# IPTV Freedom

Desktop IPTV client built with **Electron + React + TypeScript + Tailwind CSS** for providers using the **Xtream Codes** standard. The stack and visual language follow [t3code](https://github.com/pingdotgg/t3code).

## Features

- 📺 Multiple IPTV accounts (host · username · password) — add, edit and remove
- 🔎 Browse and search live TV, movies and series
- ▶️ Built-in player — live via [`mpegts.js`](https://github.com/xqq/mpegts.js) (MPEG-TS / MSE) with an automatic buffer that ramps up when the stream stalls; VOD `.mp4` via the native `<video>` element
- ⬇️ VOD downloads (movies and series) with resume and a queue that respects the provider's connection limit
- ⭐ Favorites, saved per account
- 🌍 **20 languages**, with automatic system-language detection and RTL support (Arabic, Urdu)
- 🎨 **Light and dark themes** (t3code design tokens: zinc + violet, DM Sans)
- 🔒 Credentials stored locally only — no sign-up, no middle server

## Proxy configuration

Open **Accounts → Network proxy** to choose a direct connection, the system proxy,
or a manual HTTP, HTTPS or SOCKS5 proxy. Manual HTTP/HTTPS proxies support optional
username/password authentication; SOCKS5 supports unauthenticated proxies only.
Enter the proxy host and port separately (for example, `127.0.0.1` and `8080`).
Choose **HTTP** for an HTTP proxy that supports HTTPS destinations through CONNECT.
Choose **HTTPS** only when the connection to the proxy itself uses TLS. Selecting
HTTPS for a plain HTTP proxy causes TLS handshake and proxy connection errors.

The setting is shared by all accounts and covers provider API calls, live video,
recordings, VOD playback, downloads and remote images. Local playback and the dev
server bypass manual proxies. Settings are saved locally in `proxy.json` in the
application data folder; proxy credentials use the same local storage model as
account credentials. Saving applies immediately and closes existing connections:
restart playback and resume interrupted downloads afterward.

Run the networking regression tests without launching Electron:

```bash
node --test scripts/*.test.cjs
```

## Translations

The app and the landing page ship in the 20 most spoken languages in the world.

**These translations were generated by AI** and were only spot-checked for the few languages the author is fluent in. They very likely contain mistakes, awkward phrasing or wrong terminology.

**Corrections are very welcome.** If you are a native speaker and something reads wrong, please open an issue or a pull request:

- App strings: `apps/desktop/src/renderer/src/i18n/locales/<lang>.json`
- Landing page: `docs/i18n.js`

## Stack

- [Electron](https://www.electronjs.org/) + [electron-vite](https://electron-vite.org/)
- [React](https://react.dev/) 19 + [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/) v4 (CSS-first tokens) with the [t3code](https://github.com/pingdotgg/t3code) design language
- [Vite+](https://vite.plus) (`vp`) unified toolchain — rolldown-vite, oxlint, oxfmt — over [pnpm](https://pnpm.io/) workspaces
- [mpegts.js](https://github.com/xqq/mpegts.js) for MPEG-TS streams
- [i18next](https://www.i18next.com/) + [react-i18next](https://react.i18next.com/) for internationalization

## Development

Install the Vite+ CLI once (`curl -fsSL https://vite.plus | bash`), then:

```bash
vp i             # install the workspace (pnpm install also works)
vp run dev       # start the app with hot reload
vp run build     # production build
vp check         # format + lint + type-check
pnpm clean       # remove node_modules, build output and caches
```

> The interface follows the t3code visual language: flat zinc surfaces, a violet
> primary, DM Sans, and full light/dark theming, in a compact 3-pane layout.

## Project structure

```
apps/
  desktop/           Electron app (main + preload + renderer)
    src/main/        main process (window, IPC, network, disk)
    src/preload/     secure bridge (contextBridge) to the renderer
    src/renderer/    React + Tailwind UI
packages/
  contracts/         TypeScript types for the window.api IPC surface
  core/              shared domain logic (formatters, poster palette, catalog)
  ui/                design tokens + shadcn-style UI primitives
docs/                landing page (GitHub Pages)
```

## Disclaimer

IPTV Freedom is just a player. It does not provide, host or include any content, playlist or subscription. You use it with your own account from an Xtream Codes provider.
